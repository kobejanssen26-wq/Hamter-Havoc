# Animation & action catalog

> Generated by `tools/ReleaseCheck/gen_animation_docs.py` from the game's own files. **Do not edit by hand**: change `Modules/ActionCatalog.luau` or the files in `Modules/Content/` and run the script again (`release_check.py` fails when this file is out of date).

No animation id is invented anywhere. Every action works today with a built-in procedural movement; to use your own animation, publish it in Roblox Studio (Animation Editor) and paste its `rbxassetid://` into the matching file in `Modules/Content/Animations/` - then it replaces the built-in movement automatically.

## How to add or change one

1. **New character action**: add a row to `Modules/ActionCatalog.luau` (copy a neighbour), pick an existing `Pose` (or add one to `ActionAnimator.Poses`), call `ActionFx.play(player, "YourId")` on the server right after the real event happened, run this script.
2. **Your own animation**: publish it in Studio, create `Modules/Content/Animations/<Name>.luau` from `_Template.luau` with the `AssetId`, then put its name in the action's `Animation` field (or in the weapon's `Weapon.Animation`).
3. **Check**: `python3 tools/ReleaseCheck/release_check.py` and the simulation `tools/SimTests/run.sh scn_actions`.
