# Model Library

Reusable Roblox models from Hamster Plaza. Every `.rbxm` below is a genuine Roblox binary model file that can be inserted into **any** Roblox Studio place.
The catalog table is generated by `tools/ExportModels/export_models.py` from the files that really exist - do not edit it by hand.

## Use a model in another game

1. Open the `.rbxm` file on GitHub and press **Download raw file** (the download icon), or `git clone` the repository.
2. In Roblox Studio open your place, then **View -> Explorer**.
3. Right-click **Workspace** (or `ServerStorage` / `ReplicatedStorage`) -> **Insert from File...** and pick the `.rbxm`.
   (You can also drag the file from your file manager onto the 3D viewport.)
4. The model appears under the chosen parent. Read the asset's README for required scripts, attributes and the pivot.

Scripts that a model needs are **inside** the `.rbxm` (look for `Script` / `ModuleScript` children). Nothing in these files depends on the original game's
services, DataStores or remotes. No asset ids are used: everything is built from parts, so the models work in any experience.

## Update / regenerate

The source of truth is each asset's folder (`model-config.lua`, `build-model.lua`, `scripts/`) plus the game's own builder code in `src/`.
Run `python3 tools/ExportModels/export_models.py --update` to rebuild the files; `--check` tells you whether they are in sync. Details: `tools/ExportModels/README.md`.
